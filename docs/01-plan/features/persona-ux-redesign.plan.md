## 1. 개요

### 1.1 문제 정의

현재 콘텐츠 마케팅 모듈의 페르소나 설정 화면(`PersonaGate`)은 기능적으로 동작하지만, 다음과 같은 UX 문제를 안고 있다:

| # | 문제 | 영향 |
|---|------|------|
| P1 | **첫 진입 화면이 차갑다** — "AI 자동 분석" vs "직접 설정" 두 버튼만 제시하며, 사용자가 왜 페르소나가 필요한지, 어떤 결과를 얻을 수 있는지 알 수 없음 | 이탈률 증가, 기능 가치 인지 실패 |
| P2 | **Track 간 전환이 매끄럽지 않다** — Track 1(AI 분석) 실패 시 Track 2로 전환할 때 이전 맥락이 사라짐 | 사용자 좌절감, 재입력 부담 |
| P3 | **분석 결과 시각화 부족** — `PersonaConfirmation`이 텍스트 나열 형태로 AI 분석 결과의 근거를 보여주지 못함 | 신뢰도 저하, 수정 동기 부족 |
| P4 | **하이브리드 패턴 미지원** — AI 추천 결과를 기반으로 세밀하게 조정하는 흐름이 자연스럽지 않음 (별도 모달 팝업 필요) | UX 단절감, 두 트랙이 분리된 느낌 |
| P5 | **전문직 사용자 기대 미충족** — 변호사 대상 서비스임에도 일반적인 온보딩 위자드 수준의 디자인 | 브랜드 신뢰도 하락 |

### 1.2 목표

| 목표 | 측정 지표 | 목표값 |
|------|----------|--------|
| 페르소나 설정 완료율 향상 | 설정 시작 대비 완료 비율 | 85% 이상 |
| 설정 소요 시간 단축 | 평균 설정 완료 시간 | 90초 이내 |
| AI 분석 결과 수용률 | Track 1 → 바로 승인 비율 | 60% 이상 |
| 사용자 만족도 | 페르소나 피드백 평균 점수 | 4.0/5.0 이상 |

### 1.3 핵심 원칙

1. **"이 도구는 나를 이해하고 있다"** — 첫 화면에서부터 법률 전문가를 위한 맞춤형 서비스라는 인상
2. **AI 추천 → 사용자 미세조정** — 하이브리드 패턴을 기본 흐름으로 격상
3. **프로그레시브 디스클로저** — 필수 정보만 먼저, 세부 설정은 점진적으로 노출
4. **전문직 수준의 세련된 디자인** — 법률 도메인에 어울리는 절제된 프리미엄 톤

## 2. 사용자 흐름 (User Flow)

### 2.1 첫 진입 사용자 (페르소나 미설정)

```
콘텐츠 마케팅 페이지 진입
    │
    ▼
[Welcome Screen] ← 새 화면: 페르소나 소개 + 가치 전달
    │  "콘텐츠를 당신의 전문성에 맞춰 최적화합니다"
    │  미리보기 카드 (분석 결과 예시)
    │
    ├─ [추천] "AI로 자동 분석하기" ─────────────────────┐
    │     (대화 이력 있는 경우 강조 배지 표시)            │
    │                                                    ▼
    │                                          [Analysis Screen]
    │                                           분석 진행 애니메이션
    │                                           (3단계 프로그레스)
    │                                                    │
    │                                                    ▼
    │                                          [Hybrid Review Screen] ← 핵심 개선
    │                                           AI 추천 결과 인터랙티브 표시
    │                                           인라인 수정 가능 (모달 X)
    │                                           신뢰도 시각화 (레이더 차트)
    │                                                    │
    │                                                    ▼
    │                                               [Ready] ──→ 대시보드
    │
    └─ "직접 설정하기" ─────────────────────────────────┐
                                                        ▼
                                              [Smart Onboarding]
                                               개선된 위자드 (3스텝)
                                               맥락 힌트 + 프리뷰
                                                        │
                                                        ▼
                                                   [Ready] ──→ 대시보드
```

### 2.2 재방문 사용자 (페르소나 설정 완료)

```
콘텐츠 마케팅 페이지 진입
    │
    ▼
[Ready] ──→ 대시보드 (PersonaBanner 상단 표시)
    │
    ├─ PersonaBanner 인라인 수정 (전문분야/톤/시청자 빠른 변경)
    └─ "전체 수정" 클릭 → PersonaEditor 모달
```

### 2.3 Track 1 (AI 자동분석) 상세 흐름

```
Step 1: 분석 시작
    │  "대화 이력을 분석하고 있습니다"
    │  → 3단계 프로그레스 인디케이터:
    │     ① 대화 이력 수집 중...
    │     ② 전문분야 패턴 분석 중...
    │     ③ 페르소나 구성 중...
    │
    ▼
Step 2: Hybrid Review (핵심 혁신)
    │  ┌─────────────────────────────────────┐
    │  │ [레이더 차트] 전문분야 적합도       │
    │  │ ┌────────────────────────────────┐  │
    │  │ │  형사 ████████░░ 78%           │  │
    │  │ │  민사 ██████░░░░ 62%           │  │
    │  │ │  가사 ████░░░░░░ 41%           │  │
    │  │ └────────────────────────────────┘  │
    │  │                                     │
    │  │ ✓ 전문분야: [형사] [민사] ← 클릭으로 편집 │
    │  │ ✓ 타겟 독자: 일반 대중 ← 드롭다운 변경  │
    │  │ ✓ 톤: 전문가 ← 인라인 선택 변경        │
    │  │ ✓ 관심 주제: [음주운전] [사기] [+추가]  │
    │  │                                     │
    │  │ 분석 근거:                           │
    │  │ "최근 30일 대화에서 형사 관련        │
    │  │  질문이 45%를 차지했습니다"          │
    │  │                                     │
    │  │ [이 설정으로 시작하기] [처음부터 설정] │
    │  └─────────────────────────────────────┘
    │
    ▼
Step 3: Ready → 대시보드 전환
```

### 2.4 Track 2 (직접 설정) 상세 흐름

```
Step 1: 전문분야 선택 (필수)
    │  개선: 카드형 UI + 아이콘 + 짧은 설명
    │  "형사법: 음주운전, 사기, 폭행 등"
    │  "민사법: 손해배상, 계약, 부동산 등"
    │  → 선택하면 우측에 실시간 프리뷰 카드 갱신
    │
    ▼
Step 2: 톤 & 타겟 (필수)
    │  개선: 톤 + 타겟을 한 화면에 통합
    │  톤 선택: 시각적 예시 텍스트 미리보기
    │   - "전문가: '대법원 판례에 따르면...'"
    │   - "친근한: '쉽게 설명하면 이렇습니다...'"
    │  타겟: 선택 시 추천 톤 하이라이트
    │
    ▼
Step 3: 마무리 (선택)
    │  채널 스타일 + 관심 주제
    │  개선: 추천 키워드 칩 (전문분야 기반)
    │  "형사 → [음주운전] [사기] [폭행] [성범죄]"
    │  → 클릭으로 추가, 자유 입력도 가능
    │
    ▼
[Ready] → 대시보드
```

### 2.5 Track 간 전환 시나리오

| 시나리오 | 현재 동작 | 개선 후 |
|---------|----------|---------|
| Track 1 → Track 2 전환 | 빈 상태로 시작 | AI 분석 결과를 초기값으로 채워서 시작 |
| Track 2 → Track 1 전환 | 입력 내용 소실 | Track 2 입력값을 임시 저장, 돌아오면 복원 |
| Track 1 분석 실패 | 에러 → 선택 화면 복귀 | "분석이 어려워요. 직접 설정으로 안내할까요?" + 원클릭 전환 |
| 대화 이력 부족 | 분석 실패 | "대화 이력이 부족합니다" + Track 2 자동 전환 (부드럽게) |

## 3. 핵심 기능 명세

### 3.1 Welcome Screen (신규 — 페르소나 소개 화면)

**목적**: 처음 진입하는 사용자에게 페르소나의 가치를 전달하고, 두 트랙 중 적합한 방식을 안내

**구성 요소**:

| 요소 | 설명 |
|------|------|
| 헤드라인 | "당신의 전문성에 맞춘 콘텐츠를 만들어 보세요" |
| 서브텍스트 | "AI가 분석하거나, 직접 설정할 수 있습니다" |
| 가치 제안 카드 | 페르소나 적용 전/후 콘텐츠 품질 비교 미니 프리뷰 |
| AI 분석 버튼 | 기본 CTA, 대화 이력 있으면 "N건의 대화 분석 가능" 배지 |
| 직접 설정 버튼 | 보조 CTA, "약 1분 소요" 안내 |
| 건너뛰기 링크 | 하단에 작게 "나중에 설정하기" (기본 페르소나 적용) |

**디자인 참고**:
- 법률 서비스 톤에 맞는 네이비/딥블루 + 화이트 색상 조합
- 불필요한 장식 최소화, 콘텐츠 중심의 깔끔한 레이아웃
- 전문직 사용자가 "시간 낭비"라고 느끼지 않도록 간결하게

### 3.2 Analysis Progress Screen (분석 진행 화면 개선)

**현재**: 단순 스피너 + "대화 이력을 분석하고 있습니다..."

**개선**:
- 3단계 프로그레스 바: `수집 → 분석 → 구성`
- 각 단계별 구체적 메시지:
  - ① "최근 대화 이력을 수집하고 있습니다 (N건)"
  - ② "전문분야와 관심사 패턴을 분석하고 있습니다"
  - ③ "최적의 페르소나를 구성하고 있습니다"
- 단계 전환 시 부드러운 애니메이션
- 예상 소요 시간 표시 (약 10~15초)

**기술**: 백엔드 `/persona/analyze` API 응답 시간 기반으로 프론트엔드에서 시뮬레이션 (현재 API가 단일 응답이므로, 시간 기반 스텝 전환)

### 3.3 Hybrid Review Screen (핵심 혁신 — AI 추천 + 인라인 수정)

**현재 `PersonaConfirmation`**: 읽기 전용 카드 → 별도 "일부 수정" 모달

**개선 — 인라인 편집 방식**:

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  AI 분석 결과                    신뢰도: 82% ███▓░  │
│                                                     │
│  ┌─── 전문분야 분석 ───────────────────────────┐    │
│  │                                             │    │
│  │  [형사 ✓]  [민사 ✓]  [가사]  [노동]        │    │
│  │  [행정]    [기업]    [지식재산]              │    │
│  │                                             │    │
│  │  💡 형사(45%), 민사(32%) 관련 대화가        │    │
│  │     가장 많았습니다                          │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  ┌─── 타겟 독자 ──────────────────────────────┐    │
│  │  ● 일반 대중  ○ 기업/사업자                 │    │
│  │  ○ 법학 학생  ○ 법률 전문가                 │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  ┌─── 톤 ─────────────────────────────────────┐    │
│  │  ● 전문가  ○ 친근한  ○ 스토리텔링  ○ 교육형│    │
│  │                                             │    │
│  │  미리보기: "대법원 2024다12345 판결에        │    │
│  │  따르면, 해당 사안은..."                     │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  ┌─── 관심 주제 ──────────────────────────────┐    │
│  │  [음주운전 ×] [사기 ×] [+ 주제 추가]        │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  [이 설정으로 시작하기]        [처음부터 직접 설정]  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**핵심 특징**:
1. **인라인 편집**: 모달 없이 바로 수정 가능 (전문분야 토글, 타겟/톤 라디오, 주제 추가/삭제)
2. **분석 근거 표시**: 각 섹션에 "왜 이렇게 분석했는지" 짧은 인사이트
3. **톤 미리보기**: 선택한 톤으로 생성된 예시 문장 실시간 표시
4. **신뢰도 게이지**: 전체 분석 신뢰도를 시각적으로 표현
5. **변경 하이라이트**: 사용자가 수정한 항목에 "수정됨" 표시

### 3.4 Smart Onboarding (직접 설정 위자드 개선)

**현재**: 4스텝 (전문분야 → 타겟 → 톤+채널 → 관심주제)

**개선**: 3스텝으로 통합 + UX 강화

| 스텝 | 현재 | 개선 |
|------|------|------|
| Step 1 | 전문분야 (텍스트 버튼) | 전문분야 (아이콘 카드 + 대표 키워드 표시) |
| Step 2 | 타겟 독자 (텍스트 리스트) | 톤 + 타겟 통합 (톤 예시 미리보기 포함) |
| Step 3 | 톤 + 채널 스타일 | 채널 스타일 + 관심 주제 통합 (추천 키워드 칩) |
| Step 4 | 관심 주제 (자유 입력) | *(Step 3에 통합)* |

**Step 1 개선 — 전문분야 카드**:
```
┌────────────┐  ┌────────────┐  ┌────────────┐
│  ⚖️ 형사   │  │  📋 민사   │  │  👷 노동   │
│            │  │            │  │            │
│ 음주운전   │  │ 손해배상   │  │ 부당해고   │
│ 사기/횡령  │  │ 계약분쟁   │  │ 산업재해   │
│ 폭행/상해  │  │ 부동산     │  │ 임금체불   │
└────────────┘  └────────────┘  └────────────┘
┌────────────┐  ┌────────────┐  ┌────────────┐
│  👨‍👩‍👧 가사   │  │  🏛️ 행정   │  │  🏢 기업   │
│            │  │            │  │            │
│ 이혼/양육  │  │ 행정소송   │  │ M&A        │
│ 재산분할   │  │ 인허가     │  │ 회사법     │
│ 상속       │  │ 징계       │  │ 금융/증권  │
└────────────┘  └────────────┘  └────────────┘
```

**Step 2 개선 — 톤 + 타겟 통합**:
- 타겟 독자를 선택하면 추천 톤이 하이라이트됨
  - `일반 대중` → `친근한` 추천
  - `법률 전문가` → `전문가` 추천
  - `법학 학생` → `교육형` 추천
- 톤 선택 시 실시간 텍스트 미리보기:
  - 전문가: "대법원 판례에 따르면, 해당 사안은 민법 제750조..."
  - 친근한: "쉽게 말하면 이런 상황이에요. 비유를 들어볼게요..."
  - 스토리텔링: "어느 날, 한 직장인에게 갑작스러운 통보가..."
  - 교육형: "Step 1. 먼저 이 개념부터 이해해야 합니다..."

**Step 3 개선 — 채널 + 주제 통합**:
- 채널 스타일은 선택 사항임을 명확히
- 관심 주제: Step 1에서 선택한 전문분야 기반 추천 키워드 칩
  - 형사 선택 시: `[음주운전]` `[사기]` `[폭행]` `[성범죄]` `[마약]`
  - 민사 선택 시: `[손해배상]` `[부동산]` `[계약해지]` `[대여금]`
- 추천 칩 클릭으로 즉시 추가, 자유 입력도 동시 지원

### 3.5 기본 페르소나 (Skip 시나리오)

Welcome Screen에서 "나중에 설정하기" 선택 시:
- 기본 페르소나 자동 적용: `specialty_areas: ['all']`, `preferred_tone: 'professional'`, `target_audience: 'general_public'`
- PersonaBanner에 "기본 설정 사용 중 — 맞춤 설정하면 더 좋은 콘텐츠를 받을 수 있어요" 안내 배너
- 대시보드 최상단에 부드러운 알림 (한 번만 표시, 닫으면 재표시 안 함)

## 4. UX 개선 아이디어

### 4.1 시각적 가이던스 강화

| 요소 | 구현 |
|------|------|
| **전문분야 아이콘** | 각 법률 분야별 직관적 아이콘 (SVG, 모노크롬) |
| **신뢰도 게이지** | 선형 프로그레스 바 (색상 그라데이션: 초록-노랑-빨강) |
| **톤 미리보기** | 선택한 톤으로 작성된 1-2문장 예시 텍스트 실시간 표시 |
| **선택 카운터** | "1/3 분야 선택됨" 등 명확한 진행 상태 |

### 4.2 프로그레시브 디스클로저

1. **Welcome Screen**: 최소한의 정보만 (제목, 설명, 두 CTA)
2. **Track 선택**: 대화 이력 유무에 따라 추천 트랙 강조
3. **Hybrid Review**: 기본은 결과 요약, "분석 근거 보기" 토글로 상세 정보 노출
4. **채널 스타일**: 선택사항임을 시각적으로 분리 (접이식 또는 "고급 설정" 레이블)

### 4.3 맥락적 도움말

| 위치 | 도움말 |
|------|--------|
| 전문분야 선택 | "선택한 분야의 최신 트렌드 키워드를 우선 추천합니다" |
| 타겟 독자 | "독자에 따라 용어 수준과 설명 깊이가 달라집니다" |

| 관심 주제 | "추가한 주제를 중심으로 트렌드를 모니터링합니다" |
| 채널 스타일 | "유튜브/블로그 등 채널에 맞는 포맷을 적용합니다" |

도움말은 `(i)` 아이콘 hover 시 툴팁으로 표시 (모바일은 탭).

### 4.4 분석 결과 시각화

**전문분야 적합도 바**:
- 수평 바 차트 (CSS만으로 구현, 라이브러리 불필요)
- 각 분야별 AI 분석 점수(%) 표시
- 상위 N개만 기본 선택, 나머지는 토글 가능

**신뢰도 표시**:
- 전체 분석 신뢰도: 선형 게이지 + 퍼센트
- 색상 코딩: 70%+ 초록, 40-70% 노란색, 40%- 빨간색

**변경 추적**:
- AI 추천과 사용자 수정 사항을 시각적으로 구분
- 수정된 항목에 "수정됨" 레이블 (파란 점)

### 4.5 마이크로인터랙션

| 인터랙션 | 효과 |
|---------|------|
| 전문분야 카드 선택 | 부드러운 체크 애니메이션 + 배경색 전환 |
| 스텝 전환 | 슬라이드 또는 페이드 트랜지션 (200ms) |
| 분석 완료 | 체크마크 아이콘 나타남 + 결과 카드 페이드인 |
| 톤 선택 시 미리보기 | 텍스트 타이핑 효과로 미리보기 표시 |
| 관심 주제 추가 | 칩이 부드럽게 나타남 (scale 0→1) |

## 6. 차별화 포인트

### 6.1 경쟁 서비스 대비 UX 우위 요소

| 요소 | 일반 콘텐츠 도구 | 본 서비스 (개선 후) |
|------|----------------|-------------------|
| 초기 설정 | 긴 폼 + 저장 | AI 자동 분석 + 인라인 미세조정 |
| 전문분야 선택 | 텍스트 리스트 | 대표 키워드 포함 카드형 UI |
| 결과 수정 | 별도 설정 페이지 | 분석 결과 화면에서 즉시 수정 |
| 설정 근거 | 제공하지 않음 | 분석 인사이트 (대화 이력 기반 근거) |
| 톤 설정 | 드롭다운 선택 | 실시간 미리보기 텍스트 |
| 전환 비용 | 처음부터 다시 | Track 간 상태 보존 |

### 6.2 변호사 전문 도메인 특화 UX 패턴

1. **법률 전문분야 정밀 분류**: 7개 대분류 + 대표 키워드로 직관적 선택
2. **대화 이력 활용**: 기존 법률 상담 대화에서 자동으로 전문성 프로파일 구축
3. **톤-타겟 연동 추천**: 법률 콘텐츠 소비자 특성에 맞는 지능적 추천
4. **관심 주제 추천 엔진**: 전문분야별 자주 등장하는 법률 이슈 키워드 사전 제공
5. **신뢰도 투명성**: AI 분석 과정과 근거를 투명하게 공개 (전문가 신뢰 확보)

### 6.3 "이 도구는 나를 이해하고 있다" 패턴

- **첫 진입**: "N건의 대화를 분석할 수 있습니다" — 이미 사용자를 알고 있다는 인상
- **분석 결과**: "형사 관련 질문이 45%입니다" — 구체적 데이터 기반 근거
- **추천 주제**: 선택한 전문분야에 맞는 키워드 즉시 제안 — 도메인 전문성
- **톤 미리보기**: 법률 콘텐츠 맥락의 예시 문장 — 결과물 예측 가능
