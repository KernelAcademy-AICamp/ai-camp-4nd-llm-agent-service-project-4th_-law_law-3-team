# 외부 컨설팅 보고서: 대본 생성 버튼 비활성화 버그

## 1. 격차 분석
- 현재: 백엔드/프론트 모두 5자 하드코딩, 한국어 법률 키워드 실사용 길이(2~4자)와 불일치
- 모범 사례 대비 격차: "도메인 입력 특성 미반영", "중복된 매직넘버로 인한 계약 드리프트 위험"

## 2. 수정 방안 기술 평가
- 5→2 완화는 기술적으로 정합하며 하위호환성 문제 없음
- 백엔드-프론트 동시 변경 계획 적절
- 추가 권고: topic.trim() 단일화, MIN_TOPIC_LENGTH 상수화

## 3. UX 개선 제안
- placeholder 변경 필요하지만 충분조건 아님
- 비활성 버튼 사유 텍스트 표시 권장
- 뉴스 선택 후 전환 시 자동 포커스/하이라이트 처리

## 4. API 계약 일관성
- 수정 방향은 계약 정렬에 맞음
- 제약이 코드 여러 위치에 분산되어 재발 가능성 있음
- MIN_TOPIC_LENGTH 상수 관리 권고

## 5. 최종 권고
- **즉시 적용 권장**
- 핵심 보완: MIN_TOPIC_LENGTH 상수화, 입력 가이드 UX 개선
