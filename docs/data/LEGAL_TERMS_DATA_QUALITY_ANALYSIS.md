### 1.3 중복 원인

중복 `법령용어ID`는 모두 **동일 용어의 서로 다른 출처**에서 발생:

```
  출처1: "위험기계 안전인증 고시[..2023..]" → 정의A
  출처2: "안전검사 고시[..2023..]"          → 정의B (미세하게 다름)
```

리스트 타입 레코드의 배열 크기 분포:

| 배열 크기 | 레코드 수 | 비율 |

| 3 | 2,105 | 17.2% |

### 1.4 결론

- `법령용어ID`는 **레코드 단위 고유 키로 사용 불가** (리스트 평탄화 시 동일 ID 복수 발생)

| 항목 | 점수 | 근거 |

### 6.2 DONE 데이터 전환 시 주요 고려사항

1. **스키마 변경 필수**: `term` UNIQUE 제약 제거, `법령용어ID` + `출처` 복합 키 또는 auto PK
2. **평탄화 로직 필수**: 리스트 타입 레코드 15% (12,242건) 처리
3. **역추출 로직 추가**: 법령한영사전 역방향 정의에서 핵심 용어 1,254건 추가 확보
4. **공백 용어 필터**: 정규식에서 `\s` 제거 검토 (292건 오매칭 방지)
5. **full 전용 26건 보존**: 생활용어사전 출처 용어 별도 합산
6. **노이즈 용어 제외 검토**: "대통령령으로 정하는 ~" 패턴 등
