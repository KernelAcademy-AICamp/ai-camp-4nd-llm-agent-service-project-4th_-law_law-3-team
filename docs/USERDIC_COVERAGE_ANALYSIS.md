## 3. 구조적 제외 상세

### 3.1 순수 비한글 용어 (12,985개)

한글 문자가 하나도 없는 순수 영문/숫자/특수문자 용어.

**예시**: OECD, GDP, UNESCO, API, ATM, ACL, AIDS patient, compensation for damage

**MeCab에서 불필요한 이유**:
- MeCab은 한국어 형태소 분석기이므로 영문 토큰은 그대로 통과 (SL 태그)
- FTS에서 "API"로 검색하면 문서 내 "API" 토큰과 정확히 매칭됨
- userdic에 등록해도 효과 없음

**한글 정의(번역어) 커버리지 검증**:

이 12,985개 용어 중 10,716개가 한글 정의(번역어)를 갖고 있다.
예: "AIDS patient" → "후천성면역결핍증환자"

| 항목 | 수치 |
|------|-----:|
| 한글 번역어 존재 | 10,716개 |
| 번역어가 별도 용어 엔트리로 DB에 존재 | **10,714개 (99.98%)** |
| 미등록 번역어 | 2개 (조약명 특수 케이스) |

`load_legal_terms_data.py`의 역추출(reverse extraction) 과정에서
법령한영사전의 한글 번역어를 이미 별도 용어로 등록했기 때문에,
비한글 용어의 한글 정의는 **사실상 전부 커버**되고 있다.

### 3.2 공백 포함 용어 (22,249개)

한글을 포함하지만 공백이 포함된 구문형 용어.

**예시**:
- "손해 배상 책임"
- "국가 유공자"
- "전자 문서"

**MeCab에서 불가능한 이유**:
MeCab은 공백을 문장 내 토큰 분리 경계로 사용한다.
`MeCab.Tagger.parse("손해 배상 책임")`은 "손해", "배상", "책임"을
개별 토큰으로 먼저 분리한 후 각각을 분석한다.
userdic에 "손해 배상 책임"을 등록해도 MeCab이 이를 인식할 수 없다.

**FTS 영향**: 없음.
공백 포함 용어의 각 구성 단어는 이미 개별적으로 토크나이징되므로,
FTS 검색에서 구성 단어로 매칭 가능하다.
예: "손해 배상 책임" → "손해", "배상", "책임" 각각이 FTS 인덱스에 존재.

## 4. userdic 빌드 파이프라인

### 4.1 용어 로드 경로

```
PostgreSQL legal_terms (72,699개)
    │
    ├── 한글 전용 (is_korean_only=True, 2-15자) ─── 35,711개
    ├── 혼합 (한글+영숫자, 공백/괄호/가운뎃점 없음) ── 480개
    └── 괄호 포함 → 2가지 변형 추출 ──────────────── ~1,740개
                                                  ─────────
                                                  ~37,931개
    ↓
CSV 생성 (surface, cost, POS)
    ↓
mecab-dict-index 컴파일 → legal_terms.dic (37,772개)
    ↓
분해맵 생성 → decomposition_map.json (32,145 엔트리)
    ↓
회귀 수정 → priority_terms.json (683개, cost=-3000)
```

### 4.2 회귀 수정(regression fix)

userdic 등록 후 Viterbi 경합으로 일부 용어가 조사 결합 시 깨지는 현상.

| 단계 | 용어 수 |
|------|-------:|
| 회귀 탐지 (solo + particle) | 683개 |
| cost=-3000 적용 후 해소 | 618개 (90.5%) |
| 미해소 잔여 | 65개 |

**미해소 65개의 FTS 영향**: 없음.
decomposition_map.json에 분해 토큰이 등록되어 있어,
MeCab이 용어를 분해하더라도 FTS 검색에서 sub-token으로 매칭 가능.

### 4.3 전처리 (토크나이저)

| 전처리 | 대상 | 처리 방식 |
|--------|------|----------|
| 가운뎃점 정규화 | ㆍ(U+318D), ·(U+00B7) | 공백으로 변환 후 MeCab 파싱 |
| Compound 분해 | MeCab Compound 타입 | 구성 형태소로 분해 (FTS 부분검색용) |
