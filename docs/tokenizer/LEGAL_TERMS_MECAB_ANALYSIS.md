## 2. 법령한영사전 구조 분석

### 2.1 정방향/역방향 엔트리

법령한영사전(24,090건)은 **두 가지 방향**의 엔트리가 혼재:

| 방향 | 건수 | 용어 필드 | 정의 필드 |
|------|-----:|----------|----------|
| 정방향 (한글→영문) | 11,178 | 한글 법률 용어 | 영문 번역 |
| 역방향 (영문→한글) | 12,799 | 영문 법률 용어 | 한글 번역 |
| 혼합 | 113 | 한영 혼합 | 한영 혼합 |

### 2.2 정방향 예시

```
용어: 소멸시효          정의: extinctive prescription
용어: 위자료            정의: solatium
용어: 취소권            정의: right of revocation/rescission
```

### 2.3 역방향 예시 (핵심!)

```
용어: compensation for damage       정의: 손해배상
용어: tort                          정의: 불법행위
용어: default of obligation         정의: 채무불이행
용어: undue benefit                 정의: 부당이득
용어: state compensation            정의: 국가배상
용어: administrative litigation     정의: 행정소송
용어: ownership                     정의: 소유권
```

**역방향 정의 필드에 핵심 법률 용어가 존재한다.**
세미콜론(`;`)으로 구분된 복수 번역도 있음:
```
용어: abandonment    정의: 방기;보험위부;유기;투기;폐기
용어: acceptance     정의: 수락;수령;수리;승낙;접수
```

## 3. MeCab 형태소 분석 결과

| 형태소 수 | 용어 수 | 비율 | 설명 |

**92.1%의 용어가 2개 이상 형태소로 분해됨** → 사전 보강(find_terms_in_morphs)이 필수적

### 3.2 MeCab Compound 처리

mecab-ko-dic은 일부 복합명사를 `Compound` 타입으로 인식하여 분해 정보를 제공:

```
소멸시효  → NNP [Compound → 소멸/NNG + 시효/NNG]
위자료   → NNG [Compound → 위자/NNG + 료/NNG]
취소권   → NNG [Compound → 취소/NNG + 권/NNG]
적법절차  → NNP [Compound → 적법/NNG + 절차/NNG]
항소심   → NNG [Compound → 항소/NNG + 심/NNG]
```

토크나이저에서 Compound를 구성 형태소로 분해하여 FTS 부분어 검색을 가능하게 한다.

### 3.3 MeCab 오분석 사례

| 용어 | MeCab 분해 | 문제 |
|------|-----------|------|
| 법정이율 | 법정 / **이** / 율 | "이"를 주격조사로 오인식 |
| 생활안전국 | 생활 / **안** / 전국 | "안전국"을 "안+전국"으로 오분해 |
| 이동단속반 | **이** / 동단 / 속반 | "이동"을 관형사+명사로 오분해 |
| 비상주감리원 | 비상 / 주 / **감** / 리원 | 형태소 경계 오류 |
| 재외국민보호과 | 재 / 외국 / **민보** / 호과 | "국민보호"를 "민보+호"로 오분해 |

### 3.4 주요 법률 용어 MeCab 분석

## 6. DB 스키마 설계

### 6.1 현재 스키마 (`legal_terms` 테이블)

```
id (PK), term (UNIQUE), term_hanja, definition, source,
source_code, serial_number, term_length, is_korean_only,
priority, created_at, updated_at
```

→ `term`이 UNIQUE이므로 동일 용어의 복수 정의를 저장할 수 없음

### 6.2 제안 스키마 (복수 정의 지원)

[DONE] 데이터의 특성을 반영하여 **법령용어ID, 법령용어, 법령용어정의** 중심으로 설계:

```
법령용어ID (법제처 원본 ID, 레코드 단위 고유)
법령용어명 (한글)
법령용어정의
```

- 동일 용어가 여러 법령에서 정의될 수 있으므로, **법령용어ID를 기준**으로 저장
- `term` UNIQUE 제약 제거 → 같은 "손해배상" 용어에 대해 복수 레코드 가능
- 토크나이저는 여전히 `SELECT DISTINCT term` 으로 고유 용어만 로드
