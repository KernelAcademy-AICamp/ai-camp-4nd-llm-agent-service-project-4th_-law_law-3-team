## 3. 실제 LanceDB 청크 기반 토크나이징 테스트

### 3.1 테스트에 사용한 실제 청크

각 청크는 LanceDB `legal_chunks` 테이블에서 키워드 검색으로 추출했다.

#### 청크 1: 손해배상 (판례)

```
source_id:     76396
title:         손해배상청구사건
data_type:     판례
case_number:   84나3990
court_name:    서울고법
case_type:     민사
judgment_type: 제11민사부판결 : 상고
date:          19860115
chunk_index:   0/2
match_count:   11,163 (LanceDB 내 "손해배상" 포함 판례 청크 수)
```

**원문 발췌:**
> 수술당일 환자측으로부터 집도의와 마취담당의를 특정한 특정수료신청을 받고 이를 승낙하고서도 불과 2주간 수술과 수련을 한 수련의(인턴)에게 수술 및 수술회복조치를 담당하게 하여 그 결과 수술회복과정에서 의료사고가 발생하였다면 병원측에서 위 사고가 위 수련의의 경험부족으로 인한 것이 아니라 약물 자체의 부작용이나 환자의 특이체질등 병원측에 책임없는 사유로 인한 것임을 밝히지 못하는 이상 위 사고는 위 병원 수술과 의사들이 경험이 부족한 수련의에게 수술 및 수술회복조치를 담당하게 한 수술관리상의 잘못으로 인한 것으로 추정함이 상당하다.

### 3.2 MeCab 토크나이징 비교: 기본 vs userdic

실제 청크 문장에서 발췌한 구절로 기본 MeCab과 userdic MeCab의 형태소 분석 결과를 비교한다.

#### 변화 없음 (기본 MeCab이 이미 올바르게 처리)

| 구절 | 출처 | 기본 MeCab | userdic MeCab |
|------|------|-----------|--------------|
| `소멸시효로 인하여 채무가 소멸되어` | 판례 72981 | 소멸시효/로/인하/여/채무/가/소멸/되/어 | (동일) |
| `불법행위의 예방 및 단속에 관한 업무를 담당하는` | 법령 002018 | 불법행위/의/예방/및/단속/에/관한/업무/를/담당/하/는 | (동일) |
| `일반채무불이행으로 인한 손해배상액의 확정시기` | 판례 72312 | 일반/채무불이행/으로/인한/손해/배상액/의/확정/시기 | (동일) |
| `부동산업 등 대통령령으로 정하는 업종` | 법령 011474 | 부동산업/등/대통령령/으로/정하/는/업종 | (동일) |
| `손해배상청구사건` | 판례 76396 제목 | 손해배상/청구/사건 | (동일) |

> `소멸시효`, `불법행위`, `채무불이행`, `손해배상` 등은 MeCab 기본 사전(mecab-ko-dic)에서도 복합명사로 인식한다.

#### 변화 있음 (userdic이 개선한 케이스)

**Case A: 법정이율 (오분석 수정)**

```
구절: "민사상의 법정이율을 현실화하여 채권자에 대하여는"

userdic:     민사/상/의/법정이율/을/현실/화/하/여/채권자/에/대하/여/는
                        ^^^^^^^^
변화: "법정/이/율" (3토큰) → "법정이율" (1토큰)
DB 메타: source_code=법령한영사전, source_count=2, definition="statutory interest rate"
분해맵: 법정이율 → [법정, 이율]
```

**Case B: 부당이득 (오분석 수정)**

```
구절: "부당이득의 성부"
출처: 판례 72981 (서울고법 71나2479 임금등청구사건)

기본 MeCab:  부당/이득/의/성부
userdic:     부당이득/의/성부
             ^^^^^^^^
변화: "부당/이득" (2토큰) → "부당이득" (1토큰)
DB 메타: source_code=한영역추출, source_count=1, definition="undue benefit"

```

**Case C: 분양전환 (신규 인식)**

```

                                        ^^^^^^^^
```

```
             ^^^^^^^^
변화: "배상/청구" (2토큰) → "배상청구" (1토큰)
```

**Case E: 부당이득반환 (3토큰→1토큰)**

```
구절: "부당이득반환청구"
출처: 조합 테스트

기본 MeCab:  부당/이득/반환/청구
userdic:     부당이득반환/청구
             ^^^^^^^^^^^^
변화: "부당/이득/반환" (3토큰) → "부당이득반환" (1토큰)

분해맵: 부당이득반환 → [부당이득, 이득, 반환]
```

## 4. 발견된 특이 사항

### 4.1 문맥 의존적 Viterbi 경로 차이

MeCab은 Viterbi 알고리즘으로 최적 경로를 선택한다. userdic 등록 후 **단독 입력과 문맥 입력에서 다른 결과**가 나올 수 있다.

#### 4.1.1 대표 사례: `저당권`

```
"저당권" 단독 입력:
  기본 MeCab: 저당권(NNG)
  userdic:    저당권(NNG)     ← 정상 (단독에서는 OK)

"저당권의 설정" 문맥 입력:
  기본 MeCab: 저당권/의/설정
  userdic:    저당/권/의/설정    ← regression (조사 '의'가 붙으면 깨짐)

"이 사건 부동산에 관한 저당권을 설정하였다" 문맥 입력:
  기본 MeCab: .../저당권/을/설정/...
  userdic:    .../저당/권/을/설정/...    ← regression (조사 '을'이 붙어도 깨짐)

"저당권 설정 계약" 문맥 입력:
  기본 MeCab: 저당권/설정/계약
  userdic:    저당권/설정/계약    ← 정상 (공백으로 분리되면 OK)
```

**원인**: `저당`(2글자)이 한영역추출 소스로 DB에 등재되어 userdic에 cost=100으로 등록됨. 문맥에서 조사(`의`, `을` 등)가 바로 뒤에 올 때 Viterbi가 `저당`+`권`+조사 경로를 `저당권`+조사 경로보다 낮은 비용으로 평가하여 선택.

#### 4.1.2 `저당`의 DB 진입 경로

`저당`은 원본 `[DONE]lawterms.json`에 직접 존재하지 않는다. `load_legal_terms_data.py`의 **한영역추출(reverse extraction)** 로직에 의해 DB에 진입:

```
원본 레코드 (법령한영사전):
  법령용어명_한글: "mortgage"  (영문 용어)
  법령용어정의:   "담보;저당;저당권"  (한글 정의)

역추출 과정:
  1. 법령용어코드명 == "법령한영사전" → 대상
  2. 정의 "담보;저당;저당권"을 세미콜론으로 분리 → ["담보", "저당", "저당권"]
  3. 각각 한글 전용 2-10자 필터 통과
  4. 3개 모두 한영역추출 소스(source_code="한영역추출")로 DB에 등록

결과: "담보", "저당", "저당권" 모두 userdic에 등록
  → "저당"(2자)과 "저당권"(3자)이 Viterbi 경합 발생
```

- **DB 메타**: `저당` — source_code=한영역추출, source_count=1, definition="[한영역추출] mortgage"
- **DB 메타**: `저당권` — source_code=한영역추출, source_count=1, definition="[한영역추출] mortgage"

#### 4.1.3 Regression 정량 분석

userdic 35,196개 용어 중 한글 3자 이상 + 단독 테스트 정상인 2,924개를 대상으로, 14개 조사를 붙여 regression 여부를 테스트:

**단독 테스트 regression** (term 자체가 분해되는 경우): **4개**

**context regression의 근본 원인**: 용어의 끝 1-2글자 + 조사가 시스템 사전(mecab-ko-dic)에 등재된 다른 단어와 일치할 때 발생. 예:

```
감시인 + 도 → 감시 + 인도  (인도 = India/sidewalk, 시스템 사전)
경계선 + 의 → 경계 + 선의  (선의 = good faith, 시스템 사전)
가공선 + 로 → 가공 + 선로  (선로 = railway track, 시스템 사전)
감찰부 + 과 → 감찰 + 부과  (부과 = imposition, 시스템 사전)
공민권 + 을 → 공민 + 권 + 을  (저당권과 동일 패턴)
```

#### 4.1.4 FTS 검색 영향도

- 분해맵이 있으므로 복합어와 서브 토큰 모두 FTS 인덱스에 포함됨
- `저당권`이 `저당+권`으로 분해되어도 `저당`과 `권`이 모두 인덱싱됨
- 사용자가 `저당권`으로 검색 시 쿼리 토크나이저도 같은 분해를 수행하므로 매칭에 지장 없음
- **심각도**: 낮음. FTS 검색 결과에는 실질적 영향 없음

## 6. 결론

### 개선된 점

1. **오분석 수정**: `법정이율`, `부당이득`, `분양전환` 등 기본 MeCab이 잘못 분해하던 복합명사를 userdic으로 직접 인식
