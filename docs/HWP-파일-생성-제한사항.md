# HWP 파일 생성 제한사항

## 문제점

한국 정부, 법원, 변호사들이 주로 사용하는 **HWP(한글)** 파일을 서버에서 직접 생성하는 것이 현재 기술적으로 어렵습니다.

### 시도한 방법

| 방법 | 결과 |
|------|------|
| `python-hwpx` 라이브러리 | HWPX 파일 생성되나 한글에서 열리지 않음 |
| `pyhwp` 라이브러리 | **읽기 전용**, 생성 기능 없음 |
| `pyhwpx` (pywin32 기반) | Windows + 한글 설치 필수, 서버 환경 불가 |

### 근본적 원인

1. **HWP 포맷**: 한컴 독점 포맷으로 공식 SDK 없이 완전한 생성 불가
2. **한컴 SDK**: C++/C# 전용, Windows만 지원, 유료 라이선스 필요
3. **한컴오피스 Web API**: 기업용, 구축 비용 높음

---

## 현재 솔루션

| 포맷 | 지원 여부 | 한글에서 열기 |
|------|-----------|---------------|
| **PDF** | ✅ 지원 | 보기만 가능 |
| **DOCX** | ✅ 지원 | ✅ 열기/편집 후 HWP로 저장 가능 |
| **HWP** | ❌ 미지원 | - |

**사용자 워크플로우:**
```
DOCX 다운로드 → 한글에서 열기 → "다른 이름으로 저장" → HWP 선택
```

## 향후 개선 방안

### 옵션 1: 한컴 Hwp SDK 도입 (기업용)
- **비용**: 유료 라이선스
- **환경**: Windows 서버 필요
- **장점**: 완벽한 HWP 지원

### 옵션 2: 한컴오피스 Web API 도입
- **비용**: 구축형 서비스, 상당한 비용
- **장점**: 웹 브라우저에서 HWP 직접 편집 가능

### 옵션 3: 현상 유지 (DOCX + PDF)
- **비용**: 무료
- **단점**: 사용자가 한글에서 변환 필요
- **권장**: MVP 단계에서 합리적인 선택
