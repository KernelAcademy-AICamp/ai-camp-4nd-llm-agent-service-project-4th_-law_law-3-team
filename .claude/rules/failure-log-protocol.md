# Failure Log Protocol

모든 에이전트는 이 프로토콜을 **항상(ALWAYS)** 따라야 합니다.

## 1. 작업 시작 전 (필수)

**모든 작업 시작 전** `.claude/FAILURE_LOG.md`를 반드시 읽고 확인합니다.

- 기록된 실패 패턴과 현재 작업의 관련성 확인
- 관련 실패가 있으면 재발 방지 조치를 적용
- "이전에 같은 오류가 있었다"는 사실을 인지하고 작업

## 2. 실패 발생 시 즉시 기록 (필수)

다음 상황 발생 시 **즉시** FAILURE_LOG.md에 기록합니다:

| 상황 | 조치 |
|------|------|
| 외부 CLI (Gemini/Codex) 실행 실패 | 에러 메시지 원문 포함 기록 + 사용자 보고 |
| 빌드/린트/타입체크 실패 | 원인과 해결 방법 기록 |
| 워크플로우 규칙 위반 발견 | 위반 내용과 정정 조치 기록 |
| 동일 오류 2회 이상 반복 | Critical로 에스컬레이션 |
| API 호출 실패 | 에러 코드와 원인 기록 |

## 3. 절대 금지 사항

- 오류 발생 시 기록 없이 자체적으로 회피/우회
- PM이 사용자 보고 없이 프롬프트 임의 변경
- 외부 CLI 실패를 건너뛰기 (사용자 승인 없이)
- Failure Log 기록을 "나중에 하겠다"며 미룸

## 4. Failure Log 위치

- 파일: `.claude/FAILURE_LOG.md`
- 형식: FAIL-NNN 순번 체계
- 심각도: Critical / High / Medium / Low
